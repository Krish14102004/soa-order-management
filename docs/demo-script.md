# Demonstration Script

Phase 6 deliverable. Prepare this after the end-to-end workflow is implemented and verified.

Suggested demonstration:
1. Show the architecture and identify consumer, registry, ESB, and providers.
2. Show providers publishing service metadata.
3. Discover the Order Service from the registry.
4. Inspect the service/data contract.
5. Submit a valid order through the ESB.
6. Follow the correlation ID through the message trace.
7. Submit an invalid request and show contract validation.
8. Explain how the implementation demonstrates the four SOA tenets.
